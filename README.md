# Упрощенная CRM-система для сохранения данных пользователей

## Описание проекта

Данный проект представляет собой упрощенную **CRM-систему**, реализованную на чистом **JavaScript** без использования библиотек или сборок. Приложение работает в паре с локальным сервером, который предоставляет **REST API** для управления данными пользователей.

На одной странице отображается таблица с данными клиентов. Реализованы функции поиска по таблице с использованием автодополнения и сортировки данных по ID, ФИО, дате создания и дате изменения. Контакты пользователей отображаются с помощью всплывающих подсказок. Внесение данных, изменение и удаление осуществляется через модальные окна с плавной анимацией.

Если на сервере произошли изменения, при открытии модального окна для изменения данных будет выполнен запрос на сервер для актуализации информации о пользователе.

## Установка и запуск сервера

Перед запуском убедитесь, что у вас установлена **Node.js** версии 12 или выше.

1. Клонируйте репозиторий:
```
git clone https://github.com/torkvata87/crm.git
cd crm-frontend
```

3. Для запуска сервера выполните команду:
```
cd crm-backend
node index
```
   Для остановки сервера нажмите сочетание клавиш `CTRL+C`.

4. После запуска сервер API будет доступен по адресу `http://localhost:3000`.

## Реализация упрощенной CRM-системы

Все методы API (GET, POST, PATCH и DELETE) локального сервера ожидают тело запроса в формате JSON и возвращают ответы также в формате JSON.

Объект клиента имеет следующую структуру:
```javascript
{
  id: '1234567890',
  createdAt: '2021-02-03T13:07:29.554Z',
  updatedAt: '2021-02-03T13:07:29.554Z',
  name: 'Василий',
  surname: 'Пупкин',
  lastName: 'Васильевич',
  contacts: [
    {
      type: 'Телефон',
      value: '+71234567890'
    },
    {
      type: 'Email',
      value: 'abc@xyz.com'
    },
    {
      type: 'Facebook',
      value: 'https://facebook.com/vasiliy-pupkin-the-best'
    }
  ]
}
```

## Технологии и инструменты

- **JavaScript** - язык программирования.
- **HTML/CSS** - разметка и стилизация.
- **CSS** - использование масок для ввода данных.
